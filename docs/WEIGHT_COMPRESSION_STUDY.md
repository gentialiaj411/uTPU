# Lossless weight compression study

Generated by `tools/wcomp/weight_compression_study.py`.

## Scope and measured stream

The packer is `tools/decode/pack_decode_image.py`; the RTL prefetcher in `rtl/decode/top_decode.sv` performs four seeks per token: embedding code row, embedding scale row, the layer tail, and the classifier region. The classifier row seek makes row-granular random access mandatory. `rtl/decode/qspi_reader.sv` then emits the selected range in address order; it has no decompression or random seek inside a compressed block.

The measured raw streams are **10684413 B/token** for 15M and **6613245 B/token** for pruned K=8192. The 15M number agrees with `run_decode_rtl.py`'s `stream_bytes_per_token` formula and the recorded DDR result.

## Hardware feasibility and verdict

A canonical Huffman decoder belongs between the QSPI byte stream and the existing FIFO/weight consumer. A 12–15-bit two-level table (prefix table plus suffix table) can produce one symbol/cycle; two replicated lookup paths can produce two symbols/cycle. For a 15M stream, the compute side consumes roughly 0.87 B/cycle at the compute floor, so one decoded byte/cycle is sufficient with a small FIFO. Two symbols/cycle is the safer implementation point for code-length skew and backpressure.

A practical estimate is 1–2 BRAM36 for code tables/FIFO state and roughly 500–1,500 LUTs for a one/two-symbol canonical decoder, plus a few hundred LUTs for the block directory and refill FSM. Against the recorded xc7s50 budget (~20.8k/32.6k LUT, 67/75 BRAM36, 73/120 DSP), the LUT cost is acceptable but BRAM headroom is only about eight BRAM36 and timing/placement are material risks. Metadata remains raw and must bypass the decoder. The decoder adds a block-start latency of approximately 16–40 cycles, hidden by the existing 4 KiB prefetch FIFO except at short embedding seeks.

The legacy 15M image conditionally clears the 10% bar (+11.4% projected with Huffman-15), but the planned K=8192 default reaches only +5.7%. Overall verdict: **NO-GO for the planned default**; conditional GO for legacy 15M only if that image remains a target. The script includes bit-exact reference encode/decode round trips; no RTL was started because the default verdict is NO-GO.
